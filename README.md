# Hegemony Automa

GitHub Pages版は https://dokkoishoichiro.github.io/hegemony-automa/ で利用できます。`dist/index.html` をブラウザで直接開くこともできます。Node.jsがある場合は、このフォルダで `npm start` を実行し http://127.0.0.1:4173 を開きます。

## 操作

AIカードの4チェックでは、保存済みの政策、企業、労働者、資源から判定案と移動段数を表示します。カードのボーナスは最初のチェックより先に適用した仮想盤面で判定します。政策チェックとストライキチェックは盤面記録から計算します。商品・サービスでは、海外市場を在庫なしの供給元として扱い、贅沢品の基本価格6に政策6の関税（A:+6、B:+3、C:+0）を加えて自動計算します。健康と教育は海外市場から購入しません。労働者チェックは、熟練労働者の追加や共同農場への事前配置も反映した失業者数、空きスロット、雇用可能人数、設立可能な労働組合、デモ差分を計算します。通常AWの実行時は、最大3個の制限内で労働組合設立を含む全合法配置を比較します。未対応の盤面構成、カード転記との不一致は確認待ちとして表示し、推測で確定しません。

カードのボーナスは対象となる最初のチェックより先に仮想盤面へ適用します。カード#13の購入前収入、#14の共同農場、#29の2法案、#30の投票駒追加も、判定と実行の両方へ反映します。自動判定案は確定前に編集でき、確認後に従来どおり優先順位へ反映します。

保存データのない端末で初めて開くと、初期設定ダイアログを1回だけ表示します。2人用セットアップをその場で適用でき、「今は設定しない」を選んだ場合も次回から自動表示しません。上部の「新しいゲーム」からいつでも同じ初期設定を開けます。キャンセル時は現在の記録を保ち、開始を確定した後も「ひとつ戻す」で元のゲームに戻せます。

2人用では「労働者オートマ＋資本家プレイヤー」「資本家オートマ＋労働者プレイヤー」に加え、フェイズ進行を確認する「資本家オートマ vs 労働者オートマ」を選べます。資本家オートマ戦は各手番を労働者プレイヤー→資本家オートマの順で進めます。両オートマモードでは、WCAとCCAがそれぞれ独立した行動・政策優先順位、脇置きカード、AI山札と捨て札を持ちます。1手番内を労働者→資本家の順で実行し、5組の手番後に生産・投票・得点・準備へ進み、次ラウンドは労働者から再開します。政策変更時は、それぞれの望む政策位置に従って両方の政策優先順位を別々に更新します。資本家オートマは提供されたAIカード6枚（#5・#7・#9・#20・#21・#29）をシャッフルし、公式の初期優先順位から4チェックを自動処理します。両オートマの検証モードに限り、6枚を使い切った後は捨て札を再シャッフルしてゲーム終了まで進められます。開始時の価格調整と条件を満たす貸付金1枚の返済にも対応しています。資本家の法案提議は政策優先順位から対象と提議先を自動選択し、通常提議・即時投票・第5ラウンド制限・#5と#29のボーナスまで盤面へ反映します。

3・4人は表示のみ（無効）です。移民カードの技能、資本家の市場4枚は実物から選択。省略時は確認事項として残ります。盤面・個人ボード・優先順位・手番を初期化しますが、操作履歴を残し、取り消しで元に戻せます。既存のゲーム記録がある場合は初回ダイアログを表示しません。

初期スーパーマーケットは添付JSONが3スロット、基本ルールp.10が2人配置と食い違うため、セットアップ適用時に専用の2スロット補正を保存します。元の企業JSONは変更しません。公共サービスの単価は未確認として残します。

「手番」「政策」「企業と労働者」「国家」「輸出入」「個人ボード」のタブで切り替えます。「輸出入」は、資本家または中産階級がオートマの参加設定だけで表示します。資本家オートマの新規ゲームでは、開始前に輸出カード1枚と政策6に対応する商取引カードを必須入力します。小さな「デバッグ」ボタンで、未熟練移民・ランダムな企業市場4社・公式ルール例の輸出カードと商取引カード（ぜいたく品8・本体30・関税A 16／B 8）を一括入力できます。輸出カードの品目・数量・受取額、商取引カードの食料・ぜいたく品・価格を保存し、政策6に連動する海外市場の輸入価格と関税を表示します。政策画面には7政策の現在位置と、位置から決まる主要な値を表示します。

企業と労働者は、階級ごとの盤面枠に設立済みの企業だけをカードとして表示します。提供された企業データから、資本家企業28件、中産階級企業16件、公共企業9件、共同農場2枚を登録しました。「企業を設立」から企業を選び、技能が合う失業労働者がいれば各スロットへの割り当てと誓約状態を同時に記録できます。共同農場は開始時には表示されません。2人用の初期公共企業は、公立大学（教育4・労働者2人）、地方テレビ局（影響力3・空き2枠）、公立病院（医療4・労働者2人）です。賃金、操業、ストライキ、労働者の階級・技能・誓約をカード上で確認できます。オートマまたは不参加階級が管理する賃金は、政策2の最低賃金に連動します。

投票駒は政策画面にあります。目視できる「袋の外」の個数を階級色ごとに入力し、各色25個から差し引いて袋の中を表示します。2人用の初期値は袋の外17個、袋の中8個です。

国家画面には国庫と、共通ボード上で国家が供給する医療・教育・影響力を表示します。公共医療と公共教育の価格は政策4・5に連動します。国家プレイヤーが参加する構成では、個人ボード側で食料・贅沢品・個人影響力を管理します。今回の盤面形式は保存キーを更新したため、以前の端末内保存は読み込まず、新しいゲームから再構成します。

個人ボードは参加している階級だけを選択できます。現在の2人用では労働者階級と資本家階級を表示し、不参加の中産階級と国家は隠します。労働者数は企業上、失業労働者エリア、労働組合欄の労働者コマから数え、人口を個人ボードの対応表（10–11人で人口3、12–14人で人口4、以後3人ごと、30人以上で人口10）から自動計算するため、どちらも直接編集しません。労働者の組合も保存できます。企業画面では階級・技能別の失業労働者も記録できます。資本家の商品価格は食料9/12/15、健康・教育・ぜいたく品5/8/10から選びます。富マーカーは得点計算フェイズで資本段階に従って自動更新します。数値の空欄は未確認、0は確認済みのゼロです。

新しい盤面フォームは「企業を保存」「個人ボードを保存」「共通盤面を保存」で確定します。保存・取り消し・JSONバックアップに含まれます。盤面記録はチェックと行動対象の自動判定に使います。チェック途中に盤面を訂正した場合は、必要なチェックまで戻して再確認してください。

行動画面では、引いたAIカードの番号、チェック順、政策、ボーナス、特殊アクション、影響力記号を常時表示します。自動判定された内容を確定すると、BGSの資金・商品・販売元在庫・販売収入、AWの失業労働者・企業スロット・誓約状態、STRのストライキトークン、PBの法案マーカー・影響力・政策位置・政策優先カード・投票駒を一括更新します。政治的圧力では労働者の投票駒3個を袋へ移します。購入では、必要数を1か所から買えた後に別の供給元から人口分を追加購入する条件も反映します。確定前の盤面記録が変わっていて処理できない場合は、途中状態を保存せず停止します。

即時投票を行わないPBは、提議元・提議先を投票待ちの法案として政策タブへ登録します。生産フェイズ後、政策番号順に投票します。補充数と各派閥の賛否を確認し、実物の袋から5個引いて色別の個数を入力します。労働者オートマの賛否と影響力処理はルールから判定し、「AIカードを引く」は1回ごとの50%抽選に置き換えます。可否、VP、政策位置、法案マーカー、袋内外のキューブを一括更新します。即時投票も補充を省略して同じ投票画面を使います。

生産フェイズは、生産と賃金、食料需要、IMF、納税、投票、得点計算の順で進みます。労働者プレイヤーは食料不足分について資本家と海外市場から買う数量を選択でき、労働者オートマは価格・関税・在庫から自動選択します。袋が5個未満なら補充を2回行う例外、2人用で出た中産階級キューブの破棄、同数可決、支持者VP、勝者側キューブの破棄と敗者側キューブの袋への返却にも対応しています。

第2〜5ラウンドの開始前には準備フェイズへ進みます。労働者・資本家の貸付金利息、労働者の繁栄度低下、未熟練労働者2人と政策7に応じた移民、人口の再計算を自動反映します。アプリ内の手札管理を使うプレイヤーは、各準備フェイズでアクションカード5枚を自動補充し、残した2枚と合わせて手札7枚にします。既存の実物手札管理のゲームでは補充を確認します。更新後の企業市場4枚を指定します。輸出カード1枚と政策6に応じた枚数の商取引カードは専用ダイアログで内容を入力し、準備の確定時に輸出入タブへ保存します。WCAのSTR・政策優先カードも現在の政策位置に従って復帰し、第5ラウンドでは政策7を除外します。第1ラウンドはルールどおり準備フェイズを行いません。

毎ラウンドの得点計算では、労働者階級は労働組合1個につき2VPを獲得します。資本家階級は収入を資本へ移し、資本レベルのVPと、富マーカーが右へ進んだ段階ごとの3VPを獲得します。富マーカーは左へ戻りません。第5ラウンドでは続けて最終得点へ進み、労働者の貸付金返済・政策1〜5のA位置・残金、資本家の貸付金・政策1〜5のC位置・通常倉庫と自由貿易区の商品を計算します。勝利点、各階級に有利な政策数、国家優先、袋内投票キューブ数の順で勝者を判定し、同率勝利も表示します。現在は2人用の労働者階級と資本家階級に対応しています。

開始時は、2人用では援助なしと自動判定し、資金50ごとに返済可能な貸付金をすべて返済してからAIカードを自動で引きます。将来、国家プレイヤーを追加した場合は援助エリアの受け取り処理を接続します。その後、4チェックを順に判定 → 優先順位から実行可否を確認 → 実行を確定 → 政策イベントと終了時無償行動を処理します。教育を使用するときは、Instructionカードの技能選択基準から得る熟練技能を自動決定し、失業労働者を優先して変更します。失業者がいなければ、未熟練スロットで働く労働者からランダムに選びます。

同じチェック内でも移動を合算せず入力できます。行動は画面の左側、政策は右側。いずれも中央に近いカードが優先です。

確定した操作は自動保存。「ひとつ戻す」は盤面メモを含む直前の操作を取り消します。未確定のフォーム入力は保存されません。途中のチェックを訂正するには、対象まで戻り後続をやり直します。JSONで履歴ごとバックアップ・復元できます。ファイル直開きでの保存可否はブラウザに依存するため、保存状態の表示を確認してください。

## 対応範囲

優先順位移動・同段順序・4チェック後圧縮・最優先/次点・実行カード下降・政治的圧力・政策イベント・除外/復帰・第5ラウンドの政策7除外を実装。第5ラウンドの政策6も即時投票の条件から自動判定します。

PB・BGS・STRは条件と対象を自動選択します。AWは通常の最大3個の割り当てとカード#19の全合法配置を比較し、労働組合設立と最終同点の抽選まで自動選択します。2人戦の通常の即時投票可否は、1影響力を支払った後の比較と袋内投票駒数から判定します。カード#6・#17の無料即時投票ボーナスはこの通常判断を飛ばし、法案マーカーがなくても必ず即時投票へ進みます。カード#13の購入前収入、#29の2法案、#30の投票駒2個追加は対応済みです。登録済み特殊アクションの資金・資源・盤面更新は自動処理します。投票駒を袋から引くSAと投票ウインドウでは、実物の結果を入力するか、保存済みの袋内構成から重複なしでランダム抽選できます。DEMによるVP減少は行動時ではなく、生産フェイズで実物のデモ処理に従います。資本家オートマのBCは、企業市場から転記の優先条件で対象を絞り込み、全スロットの失業労働者配置、誓約、最低賃金、設立費用、カード#7・#20の国家負担を一括反映します。「企業と労働者」タブには現在の企業市場を、費用・必要スロット・生産量とともに表示します。SCは停止中の企業から転記の優先条件で売却対象を選び、配置労働者の返却と売却収入を反映します。売却時は保存済みの賃金を変更せず、実物盤面への指示は企業カードを捨て札にする内容だけを表示します。SFMは保存した輸出カードと在庫から実行可能な取引を自動選択し、自由貿易区を先に消費して収入を反映します。輸出カードは食料・ぜいたく品・医療・教育を各2件の固定欄で入力します。資本家は取引VPを得ず、1取引ごとに1VPを得るのは中産階級だけです。カード#9の商取引先行とカード#21の追加販売も、チェック前の仮想盤面と実行の両方へ反映します。LOBは30支払いと影響力3獲得を自動処理します。

資本家オートマの対象選択は公式 C&C v1.2 の共通絞り込み規則に従い、同じ箇条書き内の候補は記載順で優先します。企業設立時の「操業中企業が最少の産業」は資本家オートマ自身の企業だけを数え、労働組合成立の判定では全所有者の企業にいる労働者階級コマを数えます。通常の企業設立では優先条件の結果として停止中の企業を設立する場合がありますが、カード#1・#26の2社目は操業可能な企業または自動化企業に限定し、該当しなければ追加設立を失います。追加生産、機械化、労働者割り当て、国有企業からの移動にも各Instructionカードの優先条件を適用します。投票駒を交換・除外するSAは労働者と資本家で共通の袋内不足判定を行い、労働者・中産・資本家の3色を入力して実行者自身の色だけを袋へ戻します。機械化トークン6枚、ストライキトークン7枚の物理上限も盤面全体で検証します。

資本家オートマは生産物が通常倉庫を超えた場合、食料・ぜいたく品を先に自由貿易区へ保管します。それでも超過し、その資源の倉庫をまだ持っていなければ20を支払って倉庫を1枚自動購入します。各資源の倉庫は1枚までで、その後の超過分は失われます。個人ボードでは資源別の倉庫所有状態を記録できます。

企業カードの賃金は、段階と企業ごとの実額を `L2（20）` の形式で表示します。

盤面が変わる自動処理は、独立した「盤面への指示」ダイアログにまとめて表示します。政策・法案・ラウンドの各マーカー、各階級のVP・資金・資源・影響力・人口・繁栄度・貸付金、企業・労働者・組合・各種トークン、投票駒の袋内外を差分表示します。優先順位カードとAIカードはアプリ内で管理するため、このダイアログには表示しません。

次ラウンドへ進む前に全政策位置を更新してください。政策の初期位置は仮入力です。

## 検証

`npm test` で優先順位・盤面・生産・投票・得点計算エンジンのテストを実行。手動裁定を使う項目は自動ルール検証済みとは扱いません。WebMCP対応環境では読み取り専用 `read_wca_turn` を公開しますが、対応ブラウザでの検証は別途必要です。

出典・未確定条件：`../markdown/wca-implementation-handoff.md`。カード原文・図像は収録していません。

労働者プレイヤー対資本家オートマでは、労働者の手番から基本アクションを1つ実行できます。失業労働者を3人まで企業・労働組合へ割り当て、商品・サービスの種類と購入先別数量を選択し、隣接区画への法案提議（即時投票を含む）、1〜2社のストライキ、デモ、政治的圧力を記録します。条件・支払い・在庫・誓約・法案マーカーを検証し、盤面への指示を表示します。新しいゲームでは手札から使用するカードを選び、基本アクションで捨てるか、対応済みのカード効果を実行できます。更新前のゲームは実物の手札管理を維持します。

労働者プレイヤーの手番では、基本アクションの前後に医療・教育・ぜいたく品を人口分使うフリーアクションを選べます。教育では対象の労働者と新しい技能を選択します。医療による労働者追加で人口が増えた場合、次の使用に必要な資源数も更新します。資源使用は基本アクションの実行回数を消費せず、労働者オートマの固定使用順には影響しません。

企業市場は、新規ゲーム・ラウンド準備・資本家オートマの2社設立ボーナスによる補充で「ランダムに引く」を選べます。未使用の企業だけから重複なく抽選し、確定前に選択結果を確認できます。前ラウンドの市場は捨て札として保持し、売却・廃棄済みの企業とともに以後の選択・抽選から除外します。企業山札が不足するときは残り枚数だけ引き、捨て札を再利用しません。

## プレイヤーのアクションカード

「新しいゲーム」から始めると、資本家または労働者の人間プレイヤーへ基本セット40枚の山札から7枚を配ります。各手番でカードを1枚選び、カード効果か基本アクションを1つ実行します。成功時にカードを捨て札へ移し、失敗時は手札と盤面を保持します。フリーアクションはカードを使いません。準備フェイズでは5枚を補充し、捨て札を山札へ戻しません。山札・手札・捨て札は保存、JSONバックアップ、取り消しの対象です。

基本セットの効果は全53種類（資本家28・労働者25）に対応しています。専門化は熟練者1人の獲得と最大3人の配置・移動、雇用ボーナスは失業者最大4人の配置と企業所有者からの支払い、工業化は食料・贅沢品企業の半額設立に対応します。追加シフトと公共部門の時間外労働では選んだ1社の賃金・生産を処理し、後者では生産後の国家からの購入も選べます。事業拡大は2社の設立と企業市場への2枚補充、ゼネストは通常2社に活動中の組合数を加えた上限でストライキを実行します。投資機会は市場の10V割引設立／山札検索の10V追加設立、技術進歩は1枚20V／2枚45Vでの機械化に対応します。労働市場の規制緩和は人数制限のない配置と2Cでの再配置、失業対策プログラムは1人5Vの国家補助、海外人材の採用はサプライからの追加、競争力のある賃金はL3設定と公共企業からの移動に対応します。グローバル・ブランディングと世界的食料危機は輸出に追加販売を組み合わせ、海外パートナーは商取引後に輸出します。海外市場の知見は2枚公開後に交換・販売を選び、公開内容を保存して継続できます。配置先と労働者・技能、賃金・設立時の配置を選び、変更内容を確認して確定します。使用条件・数量・資金・在庫を検証し、確定前に資金や資源の変化を表示します。政治・投票カードは投票駒の公開・除去・交換、政策指定と任意の法案提出、2法案の順次処理と即時投票後の復帰、世論調査による無料即時投票に対応します。公開内容と継続段階は保存され、手札は最初に1枚だけ消費します。カード公開の途中で袋が空になれば公式ルールに従い2回補充し、公開済みの駒を脇に残して残りを引きます。緊急補充では国家の影響力を増やしません。C&Cカードはまだ山札に含めません。資本家の海外販売は、輸出カードの取引を複数選んで1アクションで解決します。賃金引き上げはフリーアクションのままです。

データはユーザー提供 `hegemony_action_cards_full_v6_bonus_fixed.json` をそのまま収録しています。正当性は国家プレイヤーのトラックに属するため、現在の2人戦では適用しません。C&Cのカードは台帳に保持し、今回の山札には混ぜません。対応一覧・次の実装段階・出典は [PLAYER_CARDS.md](PLAYER_CARDS.md) を参照してください。
