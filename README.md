# Hegemony Automa

Hegemonyの実物オートマカードを使用する、非公式のプレイ補助Webアプリです。現在は2人用の労働者階級オートマ（Advanced）と資本家プレイヤーを対象とし、今後ほかの階級のオートマにも対応予定です。

## 現在の機能

- AIカードの4チェック、優先順位、行動選択
- 共通盤面、企業・労働者、国家、個人ボードの記録
- 資本家プレイヤーの基本行動
- 生産、賃金、需要、IMF、納税
- 通常投票と即時投票、オートマの賛否・影響力判断、VPと政策効果
- 毎ラウンドの得点計算と、第5ラウンド終了後の最終得点・勝者判定
- 第2〜5ラウンドの準備、利息・新規労働者・企業市場・商取引カード・優先カードの更新
- ブラウザ内保存、取り消し、JSONによる保存データの移行

特殊アクションと未対応のカードボーナスは現物を参照します。全オートマや全カードの自動処理にはまだ対応していません。

## GitHub Pages

https://dokkoishoichiro.github.io/hegemony-automa/

公開対象は `docs/` です。盤面データは利用中のブラウザだけに保存され、GitHubへ送信されません。端末間の移行にはJSONの書き出し・読み込みを使います。

企業データはユーザー提供の転記資料に基づきます。公式との提携・承認を示すものではありません。
