# Hegemony Automa

Hegemonyの実物オートマカードを使用する、非公式のプレイ補助アプリです。現在は労働者階級のAdvancedモードを対象としています。今後ほかの階級のオートマにも対応予定です。

## 現在の機能

- 手入力による優先順位の更新、行動選択、政策イベント
- 共通盤面、資本家企業、個人ボードの記録
- ブラウザ内保存、取り消し、JSONによる保存データの移行

カード条件・特殊アクション・対象選択は現物を参照して確認します。全オートマや全カードの自動処理には対応していません。

## GitHub Pages

Settings → Pages → Deploy from a branch → main /docs を選択して保存します。

`docs/` が公開対象です。実装はHTML・CSS・JavaScriptのみで、ビルドは不要です。

盤面データは利用中のブラウザに保存します。GitHubへの送信や端末間の同期はしません。ローカル版から移行する場合は、先にJSONを書き出し、公開URLを開いてから読み込んでください。

企業データはユーザー提供の転記資料に基づきます。公式との提携・承認を示すものではありません。
