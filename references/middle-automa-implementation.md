# 中産階級オートマ：インストラクション・AIカード実装

資料：ユーザー提供 `middle class.docx`。抽出本文は同じディレクトリの `middle-class-instructions.txt`。

## 実装範囲

- PB / BC / BGS / SFM / AW のチェック。
- BC / PB / BGS / AW / SFM の実行条件と対象の選択。
- 労働者階級の従業員、サプライの熟練者、追加シフトの対象選択。
- 同産業2社・8社上限、失業者のみでの設立、最低賃金、技能・階級・誓約・全枠配置、2販売元、倉庫と購入済みエリアの区別。
- 中産階級の政策希望は 1–6 B / 7 A。政策チェックの2政策と、提議対象を選ぶための政策優先順位は別の入力。
- `MCAJudge.chooseAction` は明示された優先順位の上位2つを比較する。未知のSAを「実行不能」とみなして飛ばすことはしない。
- `applyRecords` は既存 `MiddleClass.basic/free/employ` に実行を委譲する。政策案は `policyEvent` で既存 `middlePolicy` イベントへ変換する。
- 購入比較は労働者の `cheapest`、技能の照合は共通 `fillPlan`、産業・公共サービス・同点の選択と輸出の組合せは資本家の共有関数を使用。

2026-10-25：添付「中産階級AIカード一覧.xlsx」30枚を `dist/middle-ai-cards.js` に登録。元のセル本文は `middle-ai-cards.json` に保存。政策欄が空のカードにはPBがないため、空配列を保持する。#28–30のH列は追加チェック（転記の「杯」のみ表示上「場合」に修正）。他階級のカードで代用しない。

画面：3人戦の「個人ボード」で中産階級を選択し、「中産階級オートマの判断を確認」を開く。現在の盤面を変更せずに、チェックと対象選択を確認できる。カード番号を指定してボーナス・SAも確認できる。実ゲームは新規ゲームで労働者または資本家プレイヤーの3人戦を選択する。

## 2026-10-18 の照合

[公式 C&C 英語ルール v1.2](https://hegemonicproject.com/wp-content/uploads/2023/09/Crisis-Control-English-Rulebook-v1.2.pdf) 印刷p.12–13で以下を照合した。

- 購入済みの同資源がある場合、不足分を購入。既に人口分あれば人口分を新たに購入。
- 自社の販売用資源から先に購入し、足りない分を別の供給元で満たす。
- 1供給元で不足を満たし、もう1供給元に人口分の在庫があり支払える場合は追加購入する。ただし人口が増加する直前の医療を除く。
- 設立には失業中の中産階級ワーカーのみを使う。労働者階級の従業員を雇える場合は自動配置。
- 他階級の操業企業数を設立の産業比較に含めない。
- 輸出は資源ごとの販売量を最大にする（資本家と共通）。
- 割り当て効果で熟練者を得る場合、熟練者選択の自社市場に関する最初の条件を飛ばす。

[BGG掲載の公式v1.2変更履歴](https://boardgamegeek.com/filepage/275167/crisis-and-control-english-rulebook-v12) の検索結果にも、p.13の失業者限定設立・従業員自動配置の補足がある。

## 未確認：企業チェックの繁栄度加算

BGGフォーラム、関連ルール質問、公式ルール・変更履歴を検索したが、「繁栄度が完全操業企業数以下ならBC＋2」をチェック全体で1回加算するか、市場の各企業ごとに加算するか明記した回答は見つからなかった。

添付文書の段落からは全体1回とも読めるが、確定ルールとは扱わない。両解釈で移動段数が異なるとき、標準の判定は `needsReview`、`movements` は空、`alternatives` に両案を返す。呼出側が比較用に `prosperityScope: 'once' / 'perCompany'` を明示できるが、UIから両案のどちらを使用するか明示選択し、`mcaProsperityScope` に保存する。両解釈の結果が同じなら通常表示できる。

## AIカードと手番への接続（2026-10-25）

- `prepareBonus` がチェック用・実行用に共通の仮想盤面を作る。チェックは保存盤面を変更せず、実行は最新の自動選択案と一致した場合だけ反映する。
- 政府の医療／教育半額は端数切り上げ。先行生産は既存の企業生産処理で在庫と賃金を反映。補助金は政府の資金不足時に共通の強制支払い処理を使う。
- 設立時の政府負担、非メディア割引4と倉庫、サプライ熟練者、割り当て前の熟練者追加、政策2B/Cの人数制限解除、輸出ごとの追加収入／政府負担5、無料即時投票／事前投票駒2個に対応。
- SA全30枚に可否・対象選択・盤面反映を接続。投票駒は他階級と同じ入力／ランダム抽選UIを使う。
- 中産階級の初期行動順位は公式C&Cのセットアップ記載順AW・BC・BGS／PB・SFM・SA。政策は標準初期位置と希望区画から1・3・5・7を段0、2・4・6を脇置きとする。
- 開始時の価格・最低賃金・ストライキ対応・貸付金1枚の返済、終了時のぜいたく品→教育→医療、独立した移民カード、納税・得点・準備・最終得点まで接続。
- 3人戦の中産階級の参加判定と、プレイヤーの階級判定を分ける。労働者や資本家プレイヤーからも中産階級の在庫・従業員枠・影響力を参照する。
- テスト：30枚の元データ一致、ボーナスの仮適用／確定時1回適用、全SAの可否、両方の新しい組み合わせで5ラウンド完走、JSON再読込、モバイル・保存・取り消し。

## 開始時の熟練労働者の自動選択（2026-10-25）

中産階級がオートマの場合、初期企業・両階級の市場・中産階級用の移民カード2枚を反映してから、ラウンド準備と同じ `skilledAction` で初期熟練労働者を1人選ぶ。移民から得た技能は候補から除外し、手動の `middleSkill` は参照しない。選択結果と理由をセットアップ記録へ保存し、開始画面に表示する。中産階級がプレイヤーの場合は従来どおり手動で選ぶ。
