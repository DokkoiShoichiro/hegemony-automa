## 対応範囲

政府プレイヤー＋3階級オートマの4人戦。順序は労働者→中産階級→資本家→政府、1ラウンド5手番を5ラウンド。既存の独立優先順位・山札・判定・投票・生産・需要・税金・中産階級の処理を拡張し、政府用に複製していない。

手札・カード消費・補充・履歴・保存・取り消し・折り込み、輸出選択、政策提議、賃金一括変更、貸付金UI、企業カード、技能照合、企業生産、税金、勝者判定の既存処理を共有。政府の援助・イベント・政治課題・トークンは `government` に保存する。

## イベントと援助

必要量は人口・操業企業・国有企業・国家に就業する労働者から再計算する。任意数量も0で解決できない。任意支出に貸付金を作らない。提供時だけ必要数量までの先行購入を許し、提供先からの購入を禁止。海外購入は食料10・贅沢品6、自己関税なし。支出イベントは手持ち資源のみ。

提供内容は即時に相手の個人ボードへ渡さず援助エリアを置換する。各オートマの開始時に全て受領し、政府に1VP。投票駒は受領時に袋へ入れる。中産階級は購入済み資源、資本家は販売倉庫の共通保管処理へ渡す。「即時対応」の同一手番2回だけは、同じ階級への援助を合算する。

正当性トラックの範囲は1〜10、初期値2。トークンは直ちに正当性＋1し、得点時の半減後にも＋1ずつ。通常「1」はトラックのみ。未対処の任意2階級は利用者が選択し、選ぶまで確定しない。

## 政府のカード：追加本文で確認済み（2026-10-25）

初回のv6データでは、国有化は「条件を満たす資本家企業」という対象条件が欠落し、民営化の `bonus.target_class` は `null` だった。このため初回は国有化の効果を保留し、民営化の対象だけ現物確認入力としていた。

その後、ユーザーから国有化の全文と、民営化の正当性対象が資本家である旨の回答を受けた。これを出典としてカード台帳と処理・UIを補完し、基本セット全28種類の効果に対応した。

- 国有化の必要条件は1A/1B。取り除くのは現在の停止中の国有企業。対象は現在の資本家所有で、機械化トークンがなく停止している設立済み企業。市場・未建設・操業中・機械化済みの企業は候補に出さない。
- 1Aでは無償、1Bでは対象企業の費用を国庫から資本家の収入へ払う。任意支出のため資金不足時に借入を作らず、手札と盤面を変更しない。
- 配置しない選択を認める。配置する場合は、同じ階級で必要な全スロットを同時に埋める。労働者カードと中産階級の既存配置関数・スロット選択UIを共用し、技能・重複・誓約・移動元の閉鎖を検証する。初期スーパーマーケットの2人スロット補正も保持する。
- 民営化の正当性＋1は資本家に固定。旧保存データに任意の対象フィールドが残っていても使わない。
- 国有化した企業の生産・在庫・賃金・操業企業数・課税は現在の所有者から判定する。国家の食料・贅沢品は個人ボード、医療・教育・メディア影響力は公共サービスへ保管し、それぞれ生産力＋6を上限とする。労働者オートマも国家の贅沢品を購入できる。
- 所有者は企業状態の `controller` で保存し、静的カード台帳を書き換えない。共有の `HegemonyCompanyDefinitions(records)` を判定・生産・税金・表示に使う。
- 取り除いた国有企業は再び財政政策の候補にしない。国有化後に民営化された企業には `returnToState` を保存し、その企業が資本家から売却された際は、元のカードが資本家用でも公共部門の非公開企業へ返す。資本家市場に混ぜない。

ユーザー追加添付 `state class .docx` の転記は [state-personal-board.txt](state-personal-board.txt)。正当性→影響力の6段階、5Vの医療/教育購入による1VP、0Vの3個ごとの正当性、食料12V・贅沢品8V、各保管上限「生産力＋6」を照合済み。既存設定と一致し、国有化後の新しい在庫にも適用する。

公開イベントを追加・交換するカードは2枚の公開内容と継続段階を保存し、未使用カードを山札の上へ戻す。選択後にイベントを1つ解決するまで手番を終えられない。「即時対応」は同じイベントの2回目まで保存・継続する。

## ラウンド・投票・得点

通常投票フェイズの袋補充時だけ、最低正当性に対応する個人影響力（1→0、2/3→1、4/5→2、6/7→3、8/9→4、10→5）を得る。緊急補充では得ない。国家はキューブ票を持たず、個人影響力がなければ投票参加しない。最後の個人影響力を支払った後も、その票を集計する。

補充画面には国家の最低正当性・個人影響力の獲得数・獲得前後を表示する。通常補充の獲得量は `StatePlayer.votingPreview` と実行で共用する。賛否・影響力選択は他階級と同じ投票画面で行い、個人影響力0の場合も国家を隠すだけにせず不参加理由を明示する。公共メディア影響力は使用せず、結果と盤面への指示に国家の賛否・使用票数を記録する。基本ルール印刷p.12–13・28に従い、他者の法案への賛成に1票以上を出して可決した場合は1VP、自分の法案なら使用0でも可決で3VP。正当性は投票結果だけでは変化しない。

公共部門の拡大・縮小は政府が企業を選び、拡大時は充足可能な階級を選んで全必要スロットを配置する。通常の企業選択と投票結果の後に専用ステップを挟み、終了後に元の段階へ戻る。

IMF介入時は法案破棄・影響力補償とマーカー返却、政策1C・2C・3A・4B・5C・6B・7B、全賃金L1、必要な公共部門の選択、可能な限りの55V返済と残債破棄、正当性半減。納税は生産開始時の労働市場を維持する。政府参加時の準備では、国家不参加時専用の「残金50超なら自動返済」を行わない。

得点順序：イベント減点→正当性の低い2階級の合計VP→全トラック半減（切上げ）→トークン分加算→政治課題1〜5の一致につき1VP。最終得点は借入処理、食料2・贅沢品/医療/教育/メディア影響力3ごとに1VP、残国庫30ごとに1VP。個人影響力は得点しない。同点は一致政策数→国家優先→他階級の袋内投票駒。
