# 自動化の監査（2026-10-25）

## 調べた範囲

実行可能な全7構成（2人戦の労働者/資本家オートマ、両オートマ進行確認、3人戦の各階級プレイヤー、4人戦の国家プレイヤー）を対象とした。チェック、アクション、特殊アクション、ボーナス、プレイヤーの基本/フリー/カード効果、手番開始・終了、生産・需要・納税・投票・得点・準備について、手入力・判定不能・未対応の分岐を検索し、到達条件を確認した。

`tests/automation-audit.test.cjs` は3階級のAIカード各30枚を、参加構成と「初期状態」「全政策A」「全政策C」「第5ラウンド・資金/影響力/公共在庫なし」の4条件で検査する。合計1,560カード条件、6,240チェック、9,360アクション判定で、例外や未確認による停止がないことを確認した。全状態を網羅する証明ではなく、登録カードと代表条件を横断する回帰検査である。

現在のプレイヤー山札は労働者25種類、中産階級26種類、資本家28種類、国家28種類（各40枚）。全107種類に効果の実装があり、使用条件も機械判定できる。カタログに保管している未採用の拡張カードは、プレイ中の山札に含めない。

## 見つけて修正した箇所

| 対象 | 修正前 | 修正後 |
| --- | --- | --- |
| 国家不参加時のIMF介入 | 政策・法案等を実物で処理し、チェックボックスで申告 | 法案返却と影響力補償、政策変更、下段公共企業の閉鎖と労働者返却、賃金L1、返済/残債破棄を自動処理 |
| 資本家オートマの2社設立ボーナス | 補充企業を手で選ぶか別ボタンで抽選 | 実行時に最大2枚を自動補充。明示指定は任意欄 |
| 資本家プレイヤー「事業拡大」の市場補充 | 設立企業とは別に補充企業の指定が必須 | 設立企業はプレイヤーが選択し、市場の補充だけ実行時に自動抽選 |
| 次ラウンドの市場・準備 | 市場選択欄と準備内容の確認チェックボックス | 市場は実行時に自動抽選し、実行ボタンだけで確定。中産階級プレイヤーの技能・市場保持の選択は維持 |
| 3オートマの投票駒を引くSA | 別ボタンで抽選、または個数を入力しないと進めない | 実行時に重複なしで自動抽選。内訳を履歴に保存し、再読み込みで引き直さない |
| 労働者の開始時援助 | 実処理は自動なのに「現物確認」と表示。返済プレビューが援助前の資金 | 「自動受領」と表示し、援助後の資金で返済をプレビュー |
| 説明文 | 一部に「4人戦未対応」「カード効果未対応」「デモを実物で処理」の古い記述 | 現在の対応範囲と自動処理に合わせて訂正 |

直前の修正で、労働者の共同農場/熟練者追加/4人割り当てボーナスも、通常AWと同じ組合優先の配置判定に統合済み。

IMF政策は国家参加時と不参加時で同じ定数を使う。国家不参加時は定められた公共部門の下段を閉鎖する。国家参加時の企業選択は国家プレイヤーの決定として維持する。納税には生産開始時の労働市場を使う。

標準進行の抽選・市場補充は実行時にだけ確定する。入力された実物結果を勝手にランダム結果へ置き換えず、不正な内訳や重複は盤面を変える前に拒否する。

## 残す入力・確認

| 分類 | 具体例と理由 |
| --- | --- |
| プレイヤーが決める行動 | 手札、企業、配置、購入、政策、投票の賛否・影響力。国家のイベント/援助/企業/正当性を失う2階級の選択もゲーム上の決定 |
| 任意の実物結果 | 実物の投票袋・企業山札をアプリに合わせたい場合の上書き欄。SAと市場補充の標準進行では開く必要なし |
| 物理盤面への指示 | アプリが確定した資金・ワーカー等の移動を実物に反映する案内。利用者にルール判定を委ねる処理ではない |
| 実物だけで手札を管理する旧ゲーム | アプリ内山札がない保存では外部の手札補充だけ確認。通常の新規ゲームはアプリが補充 |
| 不足・不正データの修復 | 未登録カード、カード番号と転記内容の不一致、未入力の数値/輸出カード、企業の不正な労働者混在。情報を推測せず訂正を求める |
| 任意の手動補正 | 保存データ・物理盤面のずれを修正する管理機能。通常の自動判定とは独立 |

資本家・国有企業の全労働者は同じ階級である必要がある。異なる階級が混在する不正な保存状態を、生産時に任意の賃金配分として自動処理しない。中産階級企業の自営業者と労働者階級の従業員は別の合法な構成で、既存処理を使う。
